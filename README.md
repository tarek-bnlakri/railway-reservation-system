# Railway Ticket Reservation System

A high-concurrency backend system for booking railway tickets, built to explore
distributed locking, dynamic pricing, and event-driven architecture.

## Tech Stack
Node.js, TypeScript, Express, PostgreSQL, Prisma, Redis, Kafka/RabbitMQ

## Getting Started
\`\`\`bash
docker compose up -d
npm install
cp .env.example .env
npm run dev
\`\`\`
